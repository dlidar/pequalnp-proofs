# L-meta-20233

The target is the 8 by 8 matrix with mask 14466700110149527140 on inputs consisting of one row and one column. The assignment asks for a monotone circuit with at most 23 binary gates.

* Quotient24.lean verifies a 24-gate circuit for the exact target. The first six gates merge six disjoint row/column pairs. EditNear.lean verifies a 23-gate circuit whose only error on the 64 inputs is a false negative at row 1, column 2. The independent all-input evaluation in quotient.py checks every retained exact construction. The edit search in bypass.cpp tests 12,144,000 candidates from deletions and single-gate replacements of the fixed 24-gate circuit; the best has one error.
* Match.lean proves that at most six disjoint nonincident row/column pairs obey the compatibility criterion for one OR signal per pair. There is exactly one six-pair family. In row-column order it is (1,7), (2,1), (3,3), (4,0), (5,4), (7,5). The counts by size are 1, 40, 304, 596, 336, 48 and 1. The criterion is necessary because two crossed cells for two merged pairs have identical signals. It suffices because every positive input activates two different labels; inclusion in a negative code could only be a collision on both labels. A monotone decoder can take the upward closure of the positive codes. match.py independently checks that separation on every family.
* Upper.lean verifies a 27-gate circuit using shared ORs separately on each side, ANDs for rectangles and a final OR. All 93 nonempty all-one rectangles are enumerated in boxes.py. The exact cost model charges one unit per shared OR group and two per selected product, rebating one for the output. Groups have at most three labels; a triple requires a pair. bound.py independently certifies that 26 gates do not suffice in this model (24,344 checked RUP additions). With 23 gates and no false positives, at least three edges must be missed in the same model (91,904 additions). Near.lean attains three. CNFs and LRAT proofs regenerate using CaDiCaL, and check_rup.py verifies every addition.
* The general 23-gate question remains separate. search.py generates the unrestricted encoding and tests a fixed positive control. repair.py limits changes to the checked near circuit. Timeouts give no exclusion.

Build each Lean file in the pinned project environment (Lean 4.36.0). Numerical scripts require Python; the optimization scripts additionally require NumPy, SciPy and CaDiCaL. q24.txt stores the 24-gate seed for bypass.cpp in OR=1, AND=0 format.
